# 你的数据，只在你这里（PRIVACY）

> 本文件由「知人明」技能在首次运行时生成，说明你的数据存在哪、怎么删。
> 内容源：`skill/references/ethics.md` §3。修改隐私承诺时先改 ethics.md，再同步本模板。

## 数据存在哪

所有数据都在你工作区的这个目录里，不离开你的电脑：

```
zhibi-data/
├── profiles/          # 画像文件：self.json（你）和 <化名>.json（你建档的每个人）
├── usage-log.jsonl    # 本地运行日志：只记事件名、时间、版本，不记聊天内容和画像内容
└── PRIVACY.md         # 本文件
```

## 三条承诺

1. **不出端。** 画像内容、你录入的线索原文，不会被发往任何外部服务。生成画像和报告需要模型在线推理，但画像文件本身只读写本地目录。
2. **建议化名。** 给他人建档时用顺口的称呼就好，别写真名。技能不存储可识别第三方真实身份的信息。
3. **删得干净。** 想清空全部数据，直接删除整个 `zhibi-data/` 目录——所有画像、修订记录、运行日志随目录一起消失，无云端残留，无需联系任何人。

## 想看自己的数据

画像就是普通 JSON 文本文件，任何文本编辑器都能打开。每条推断写清了依据（你说过的话）和置信度，被推翻的旧推断收在 `revision_history` 里，随时可以翻账。

## 离线说明

已有画像离线随时可看；新的访谈、推断和报告生成需要联网。断网时技能会明说，不会假装在工作。
